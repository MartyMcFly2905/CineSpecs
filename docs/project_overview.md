# Project Overview

## Nome
CineSpecs

## Descrizione
Archivio digitale interattivo di hardware cinematografico usato come oggetto di scena nei film, reale o fittizio.

## Obiettivi principali
- Catalogare film, frame e hardware.
- Mostrare tag cliccabili sopra i frame.
- Aprire sidebar con dettagli hardware e curiosità.
- Consentire a utenti autenticati di aggiungere tag.
- Tracciare autore e punteggio dei contributi.
- Gestire ruoli base: ospite, contributor e admin.

## Priorità
1. Viewer con tag e coordinate percentuali
2. CRUD essenziale
3. Login e sessioni
4. Fetch API e aggiornamenti senza reload
5. Sicurezza e validazione
6. Rifinitura UI e accessibilità
